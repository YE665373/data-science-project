# Working Hours and Life Satisfaction

## Project Overview
This project investigates the relationship between working hours and life satisfaction using data from the European Social Survey (ESS) Round 10.

## Research Question
How are weekly working hours associated with life satisfaction?

## Methods
- Data cleaning and descriptive statistics
- Exploratory data analysis
- Data visualization
- Ordinary Least Squares (OLS) regression
- Ordered Probit regression

## Tools
Python, Pandas, NumPy, Matplotlib, and Statsmodels

## Project Status
Completed analysis; documentation and reproducibility instructions are being prepared.
